# 大肥鱼 QQ Bot（基于小町 Komachi 二次开发）

把一个有性格、记得上下文、会使用工具的角色，放进你的 QQ 群和私聊——
她是 DeepSeek 社区二创的蓝发小鲸鱼娘「鲸鱼娘」，网友叫她「大肥鱼」。

## 大肥鱼是什么

**Python 3.12 · DeepSeek Harness SDK 0.1.5rc1 · OneBot 11 · Windows + WSL2 + Docker**

她可以接梗闲聊、读图、翻聊天记录、查网页、画图、听歌识曲、以图搜图，
也会从网页、X / Twitter 和小红书帖子取回图片、视频。你不必把每次交流都变成命令；
她会在授权范围内判断何时接话、何时保持安静。

| 想做的事 | 大肥鱼怎样完成 |
|---|---|
| 有性格的日常陪伴 | 默认「鲸鱼娘」群聊面 + 主人私聊「甜心肥鱼」粘人面，可切换人格；表达样本和事实资料分别管理 |
| 接着以前的话题聊 | 检索消息、摘要和人物资料，按需展开真实来源；撤回与失效内容受校验 |
| 看图、看转发、画图 | 读取实际像素、按页展开合并转发；生成或编辑图片进入后台任务 |
| 查资料、下载原媒体 | 搜索与打开网页；网页图集、公开视频、X 单帖媒体按来源取回，多项按顺序合并转发 |
| 拟人化细节 | 思考深度按消息复杂度动态路由；4 万条真人接法向量库按语境检索参考；身体状态（饿/渴/困）、群情绪、好感与特质证据制持续演化 |
| 听歌识曲与看图找源头 | auDD 指纹 + 字幕兜底识曲；SauceNao 等链路以图搜图 |
| 语音与桌面陪伴 | MiMo TTS 萝莉音语音条（音色人格可配置）；自研桌宠壳 + 状态桥 |
| 委派较复杂的工作 | 多页调研可交给只读子任务；主人可使用已启用的隔离计算和行动工具 |

功能和权限由部署者配置。公开模板默认关闭主动空间与计算；工具目录中的条目也不等于当前用户有执行权限。
私聊支持获准好友的日常聊天与许可绘图，不开放宿主文件、Shell 或远程项目控制。

## 拟人化是怎么做的

**静态规则 + 动态检索双轨。** 人设文件（`configs/persona.yaml` + 变体）沉淀了经过
544 万句真人对话语料校准的风格规则（语气词密度、起手收尾多样性、反八股铁律）；
每次回复前，还会按当前消息在 4 万条真人接法向量库（本地 bge 语义检索 + sqlite-vec KNN）
里捞最相似的情境参考，只学长度和节奏，内容禁照抄。

**思考深度模拟人脑。** 闲聊秒答、解释类想一下、数学/代码/长推理深思——按消息复杂度
动态覆盖当回合 reasoning effort；精力低时难题降档演"困了懒得深想"，被点名求助豁免。

**状态会演化。** 饿/渴/困三维身体状态随时间衰减、三餐夜宵按日程触发；群情绪五档
半衰期衰减并影响要不要开口；好感分证据累积；人格特质从日记与记忆中按证据制晋升。

这些机制全部 fail-soft：任何一层不可用（向量库未建、嵌入通道关闭、精力快照失败），
回复主链路照常工作，只是少一层拟人细节。

## 为长期运行做了哪些优化

**把聊天上下文整理成不同用途。** 固定角色规则与工具定义尽量保持稳定；当前提问、实际互动、
临时群聊观察和长期事实分别处理。最近消息只作为当轮观察，明确提问和必要引用优先保留。

**让记忆真正进入当前任务。** Agent 从 V3 记忆中按需取回原文、事实和摘要，自动召回有独立
预算，最终证据与来源一并准入；主对话在较长且稳定的历史上低频压缩；撤回与事实更正优先处理。

**让主对话继续聊天。** 群聊和私聊可并行处理独立请求，慢任务不挡后续提问。绘图、媒体下载
进入后台队列，复杂资料研究使用独立只读子任务。简单下载按原请求交付，需要分析才回主对话核对。

**先判断有没有必要，再调用模型。** 普通群消息先入库并本地合批，默认需 8 条有效新消息、
至少 5 分钟才考虑主动观察，静默后逐步退避；通过后只做一次无工具轻量判断，值得参与才加载
完整人格和记忆回复；明确互动优先响应，次数是上限，不是要求她用完的指标。

**缓存与资源都有边界。** 稳定工具目录配合服务端权限校验，减少模型前缀重排；动态注入行
（情绪/状态/语料例句）统一挂在 prompt 末尾保护前缀缓存；下载媒体有容量、时效和在用保护。
具体见[工程架构](docs/ARCHITECTURE.md)。

## 快速开始

准备一个 QQ 机器人账号、可用的文本/绘图 API，以及启用了 systemd 的 WSL2 Ubuntu 和
Docker/Compose。NVIDIA GPU 可选，用于本地向量推理。

1. 克隆项目，复制[环境配置模板](infra/wsl/.env.example)为私有 `infra/wsl/.env`，
   填入账号和服务配置。**密钥只放本地，永远不进仓库。**
2. 根据[配置参考](docs/CONFIGURATION.md)设置授权群、好友和功能开关。
3. 在 Windows 项目根目录运行 `start-everything.bat` 一键启动全部（WSL + QQ 平台 +
   群聊 + 私聊 + 监控），或 `start-xiaomachi-wsl.bat` 首次安装。
4. 按 [WSL/Docker 部署与运维](infra/wsl/README.md) 完成 QQ 登录和 OneBot 配置。
5. 在授权群 @ 她或通过获准好友私聊开始使用。工具与使用条件见[工具清单](docs/TOOLS.md)。

可选进阶：`datasets/` 放入 PersonalDialog 语料后，先跑
`scripts/analyze_personal_dialog.py` 再跑 `scripts/build_corpus_vector_store.py`
即可自建真人接法向量库；源码或人格修改后用 `rebuild-xiaomachi-wsl.bat` 发布。

## 根目录常用入口

| 入口 | 用途 |
|---|---|
| `start-everything.bat` | 一键启动全部：WSL + QQ 平台 + 群聊 + 私聊 + 监控，失败自动刷新 WSL 重试 |
| `start-xiaomachi-wsl.bat` | 首次安装或启动现有版本 |
| `stop-xiaomachi-wsl.bat` | 停止应用、侧车与看护服务 |
| `status-xiaomachi-wsl.bat` | 检查 QQ、应用和已启用组件 |
| `rebuild-xiaomachi-wsl.bat` | 发布当前工作区并重建应用，保留持久数据 |
| `open-agent-monitor.cmd` | 打开 Agent 现场监控（含记忆星图 `/memory`、日记页 `/diary`） |
| `switch-xiaomachi-model.cmd` | 切换已有模型套餐 |

QQ 管理页、登录桌面、隐藏启动和中文监控别名在 `infra/wsl/windows/`；安装与运行脚本在
`infra/wsl/scripts/`；评估、回填、审计与维护脚本在 `scripts/`。
